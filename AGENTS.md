# Agent Workflow Kit — разработка библиотеки

Это репозиторий общих инструкций и шаблонов, не бизнес-приложение и не целевой проект установки.

- Изменения самой библиотеки выполняй напрямую по запросу пользователя. Не запускай продуктовый author/reviewer/coder/tester конвейер для редакторской правки этих инструкций. Независимые испытания выполняются только по соответствующему поручению; не имитируй их.
- Перед работой прочитай README.md, READMEconnectAI.md и относящиеся навыки/правила. Для изменения навыков используй доступный skill-creator и .agents/skills/role-skill-builder/SKILL.md, сохраняя явные ограничения пользователя.
- Общий набор: .agents/skills/ и .agents/rules/. Новые профили стека: assets/stack-profiles/ конструктора. Изменяй связанные шаблоны и инструкции согласованно.
- В библиотеке нет данных реального приложения, ключей, персональных путей, рабочих окружений и истории чужих задач. Не переносить такие данные из исходного проекта.
- Не создавать .project-agents для самой библиотеки как будто это приложение. При подключении по READMEconnectAI.md цель — выбранная папка приложения, а не текущая папка библиотеки.
- Сохраняй 20канонических навыков, семь файлов правил/40ID и metadata. Явное согласие на изменение роли/набора важнее устаревшего текста старого навыка.
- Проверки соразмерны изменению: текст, ссылки, frontmatter и фактический diff. Не запускай массовые окружения/новые агенты/поведенческие прогоны без такого предмета задачи. Не объявляй невыполненное passed.
- Версию библиотеки и профиль фиксируй в library.json. В профиль приложения не переносить стек самой библиотеки или абсолютные пути разработчика.
- Внешняя публикация, push, теги и создание репозитория выполняются при соответствующем поручении пользователя. Не смешивать это с отправкой изменений рабочего приложения.
