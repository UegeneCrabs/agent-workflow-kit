# Совместимость со старым машинным gate

Этот выпуск распространяет инструкции, metadata и шаблоны. Старый workflow_gate.py, его JSON ledger/approval events/receipts и исполняемые сценарии испытания не включены.

Для новых задач действуют [правила общения](user-collaboration.md) и [координатор](../SKILL.md): выбранный результат разрешает выполнение/проверки/исправления без отдельных approvals этапов. Не требуй старые init/apply/prelaunch/active-check, не создавай фиктивное согласие пользователя и не мигрируй чужую историю автоматически.

Если в существующем проекте остались старые журналы/инструменты, они сохраняются как его локальная история. Их наличие не означает совместимости с текущим порядком или исправления прежних дефектов.
