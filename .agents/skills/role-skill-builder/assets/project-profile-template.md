# Профиль подключённого проекта

Заполняй по реальным фактам вне переносимого .agents/. Пути объявляются в AGENTS.md; профиль/история/SDK прежнего проекта не копируются. Оставляй только относящиеся разделы.

- Назначение проекта, источник требований и подтверждённые решения.
- Источник/версия/commit библиотеки и выбранный stack profile_id/profile_version; для существующего стека — явная пометка фактического обнаруженного решения.
- Фактический стек/версии, конфигурация, точки входа и структура модулей; включённые/неприменимые модули и статус «выбрано»/«настроено»/«проверено».
- Границы/контракты/типы, правила предметной области; предположения отдельно.
- SDK, менеджер пакетов и команды запуска.
- Применимые lint/format/type/test команды, их область и фактический статус.
- Хранилище, async/ETL/очереди — если используются.
- Ресурсы, чувствительные данные и внешние эффекты — по применимости.
- Проектная конфигурация архитектурных проверок — если используется.
- Пути артефактов/кешей/временных данных и ограничения общих ресурсов.
- Исходные пользовательские изменения, сбои и известные ограничения.
- Применимые правила и явно согласованные исключения.

Общение задаёт общий user-collaboration.md: пользователь описывает результат и выбирает варианты, технические сведения исследуют агенты. Внутреннее ТЗ и короткий Markdown-журнал сохраняют решения/границы для разработчика и MR. Legacy workflow_gate.py не является допуском новых задач.

Отсутствие проверки обозначай not_run/не настроена, не выдавай наличие инструмента за запуск. Настройку выполняй только в пределах задачи. Неприменимая технология не становится обязательной. Для Python используй python-tools и SDK, если их предоставляет IDE; иначе проверь реальный интерпретатор/uv среду проекта. Установка PyCharm не требуется.

Ресурсы и проверки соразмерны задаче. Для локального изменения не требуй массовой инвентаризации окружений, запуска всего проекта или новой среды каждого участника без причины. Не навязывай Python/FastAPI/БД/uv проекту с другим стеком.
