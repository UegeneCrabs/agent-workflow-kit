# Проектирование решения

## Вход и полномочия

Получай цель/контракт, текущую роль и этап, разрешённую область, исходное состояние и фактическую среду. Метод определяет процедуру, не назначает роль, не расширяет ТЗ и не разрешает следующий этап. Выполняй только часть, доступную текущей роли; аналитик возвращает предложения текстом, тестировщик продукт не исправляет. Не запускай исполнителей самостоятельно.

Прочитай [обязательные правила](../../rules/INDEX.md) и профиль по объявленному в корневом AGENTS.md пути `project_profile`. Основной фокус: BASE-01–04, ARCH-01–05; условно ASYNC-01, DATA-01–02. Остальные применимые нормы тоже действуют. Не используй отсутствующий учебный файл/сервис как обязательную зависимость. Недостающий обязательный вход или выход за границы верни координатору до записи.

## Процедура

1. Исследуй существующие компоненты и ограничения задачи. Уточняй только требования, которые нельзя установить чтением.
2. Опиши наблюдаемое поведение, переходы/ошибки, границы и владельцев ответственности. Для составных переходов назови DTO/TypedDict, поля и runtime-валидацию; отдельно обоснуй допустимые скаляры/Value Object/динамические Mapping.
3. Выбери существующие технологии и минимальное решение. Для новой абстракции или зависимости объясни необходимость и включи её в согласуемую область.
4. При наличии БД укажи место SQL/ORM, владельца транзакции, атомарность и преобразование ошибок. Для иных стеков используй их фактические слои.
5. Свяжи критерии, пути, риски и проверки. Краткое ТЗ обязательно; диаграммы/отдельное решение добавляй только для существенной сложности и в разрешённые пути.
6. Верни решение/альтернативы с основаниями, контракты и поручение реализации; не объявляй проектирование разрешением кодировать.

## Результат

Передай текущей роли/координатору наблюдаемый результат, артефакты в разрешённых путях, основания решений и проверки со статусами passed/failed/not_run/not_applicable. Невыполненное не называй успешным; новые пути, контракт или обязательная зависимость требуют решения по ТЗ. Следующий этап и внешние действия метод не разрешает.
